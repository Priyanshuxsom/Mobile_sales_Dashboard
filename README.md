# 📊 Sales Analytics Dashboard

My first Data Analytics dashboard project.

## 🎯 Project Overview

This dashboard analyzes sales performance, customer ratings,
payment methods, mobile model sales, and monthly trends.

## 📌 Key KPIs

- Total Sales: 769M
- Total Quantity: 19K
- Transactions: 4K
- Average: 40.11K

## 📊 Dashboard Features

- Sales by Mobile Model
- Monthly Sales Trend
- Customer Ratings
- Payment Method Analysis
- Daily Sales Analysis
- Interactive Brand and Mobile Model Filters

## 🛠️ Tools Used

- Power BI
- Data Visualization
- Data Analysis
